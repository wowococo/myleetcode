这道题是算法中非常经典的 **“最大子数组和”** 问题（LeetCode 53题）。

题目要求在给定的整数数组中，找到一个**连续的子数组**，使其元素之和最大，并输出这个最大和。

---

### 一、 解题思路（卡登算法 Kadane's Algorithm）

解决这道题的最优解法是 **动态规划 (Dynamic Programming)**，通常被称为 **Kadane 算法**。

#### 核心直觉：

当我们从左到右遍历数组时，对于当前元素 `num`，我们需要决定是：

1. **加入前面的子数组**（即 `currentSum + num`）；
2. **抛弃前面的累加和，以当前元素作为新子数组的起点**（即单独一个 `num`）。

什么情况下抛弃前面的累加和？

- **当前面的累加和 `currentSum < 0` 时**：一个负数加上任何数都会把这个数“拉低”，对后续的求和毫无贡献。因此必须立刻果断抛弃前面的部分，从当前数字重新开始计算。

只要边遍历边维护一个全局的最大值 `maxSum`，遍历完一次数组就能得到最终答案。

---

### 二、 边界条件与考点分析

在编写代码前，需要重点考虑以下边界与细节：

1. **切片为空或为 `nil**`：

- 属于边界输入，应该做防御性检查，直接返回 `0`。

2. **初始值设置**：

- 题目中明确提到 **“保证数组中至少有一个正数”**。但即使没有这个保证，最标准的做法也是将 `currentSum` 和 `maxSum` **初始化为数组的第一个元素 `nums[0]**`，而不是 `0`。这样可以优雅地兼容全负数等极端情况。

3. **时空复杂度**：

- **时间复杂度**：$O(N)$，只需对数组进行一次单向遍历。
- **空间复杂度**：$O(1)$，仅使用了常数级的变量存储状态，无需额外空间。

---

### 三、 Go 语言代码实现

以下是符合 Go 语言最佳工程规范的代码：

```go
package main

import "fmt"

// maxSubArray 计算最大连续子数组和
// 时间复杂度: O(N) - 仅需遍历一次数组
// 空间复杂度: O(1) - 仅使用常数级别额外变量
func maxSubArray(nums []int) int {
	// 边界处理：防御 nil 或空切片
	if len(nums) == 0 {
		return 0
	}

	// 初始化 currentSum 和 maxSum 为第一个元素
	currentSum := nums[0]
	maxSum := nums[0]

	// 从第二个元素开始遍历
	for i := 1; i < len(nums); i++ {
		// 如果当前累加和小于 0，说明前面的积累只会拖累当前值，果断重新开始
		if currentSum < 0 {
			currentSum = nums[i]
		} else {
			currentSum += nums[i]
		}

		// 实时更新全局最大值
		if currentSum > maxSum {
			maxSum = currentSum
		}
	}

	return maxSum
}

func main() {
	// 题目示例验证
	input := []int{1, 2, 5, -7, 8, -10}
	result := maxSubArray(input)
	fmt.Printf("输入: %v\n", input)
	fmt.Printf("输出: %d\n", result) // 输出: 9 (子数组为 {1, 2, 5, -7, 8})

	// 边界用例测试：单元素
	fmt.Printf("单元素测试: %d\n", maxSubArray([]int{5})) // 输出: 5
}

```

### 四、 算法演进轨迹（以示例数据为例）

对于输入 `{1, 2, 5, -7, 8, -10}`，代码的执行逻辑如下表所示：

| 索引 `i` | 当前数字 `nums[i]` | 处理前 `currentSum` | 决策逻辑                 | 处理后 `currentSum` | 全局 `maxSum` |
| -------- | ------------------ | ------------------- | ------------------------ | ------------------- | ------------- |
| **0**    | `1`                | -                   | 初始化                   | `1`                 | `1`           |
| **1**    | `2`                | `1` ($>0$)          | 保留前面，累加 $1+2$     | `3`                 | `3`           |
| **2**    | `5`                | `3` ($>0$)          | 保留前面，累加 $3+5$     | `8`                 | `8`           |
| **3**    | `-7`               | `8` ($>0$)          | 保留前面，累加 $8+(-7)$  | `1`                 | `8`           |
| **4**    | `8`                | `1` ($>0$)          | 保留前面，累加 $1+8$     | `9`                 | **`9`**       |
| **5**    | `-10`              | `9` ($>0$)          | 保留前面，累加 $9+(-10)$ | `-1`                | `9`           |

遍历结束，得到最大连续子数组和为 **`9`**。

### 💡 面试加分项（追问处理）

如果面试官追问：**“如果我不光要输出最大和，还要求输出具体是哪个子数组（比如输出 `{1, 2, 5, -7, 8}`），该怎么写？”**

你可以立刻补上记录索引的逻辑：只要在 `currentSum < 0` 重置起点时更新临时左边界 `tempStart`，在更新 `maxSum` 时同步记录最终的 `bestStart` 和 `bestEnd` 即可。
